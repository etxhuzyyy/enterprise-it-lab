## Purpose

This document defines a sample set of employee accounts for the simulated Acme Solutions Ltd. environment. It establishes the planned department structure, Organizational Units (OUs), security groups, usernames, and account types that will be implemented during the Identity & Access Management phase.

The users below are representative examples and are used for planning purposes. The full user environment will be created and managed during the IAM implementation phase.
