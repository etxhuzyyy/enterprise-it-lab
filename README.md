# Enterprise IT Lab - Acme Solutions Ltd.

This repository documents a simulated enterprise IT environment for Acme Solutions Ltd., a 150-employee organization. I am the sole IT administrator, responsible for designing, deploying, configuring, securing, documenting, and maintaining the environment.

The goal of this project is to demonstrate practical enterprise IT administration skills across infrastructure, networking, identity and access management, security, endpoint management, services, troubleshooting, and documentation.

## Project Objectives

* Design and document an enterprise IT environment from the ground up
* Configure core network and infrastructure services
* Implement centralized identity and access management
* Deploy and manage Windows and Linux systems
* Apply security best practices and administrative controls
* Document configurations, procedures, and troubleshooting steps
* Demonstrate the responsibilities and decision-making of a solo IT administrator

## Project Phases

Phase 0 - Planning & Requirements

  * Define business requirements and technical objectives
  * Design the proposed enterprise environment
  * Document network and infrastructure architecture

Phase 1 - Network Infrastructure

  * Configure network topology and addressing
  * Implement VLANs, routing, DHCP, and DNS
  * Document network configuration and connectivity

Phase 2 - Identity & Access Management

  * Deploy directory services
  * Create users, groups, and organizational units
  * Implement authentication and access controls
  * Apply appropriate permissions and policies

Phase 3 - Server Infrastructure

  * Deploy and configure Windows and Linux servers
  * Configure required enterprise services
  * Document server roles and configurations

Phase 4 - Endpoint Management

  * Configure employee workstations
  * Apply organizational policies and security settings
  * Establish standard endpoint configurations

Phase 5 - Security

  * Implement security controls and least-privilege access
  * Configure firewall and endpoint protections
  * Document security practices and administrative procedures

Phase 6 - Services & Operations

  * Deploy business-critical services
  * Configure monitoring, backups, and maintenance procedures
  * Document operational workflows

Phase 7 - Testing & Troubleshooting

  * Test connectivity, authentication, permissions, and services
  * Simulate common IT incidents
  * Document troubleshooting processes and resolutions

Phase 8 - Documentation & Final Review

  * Complete technical documentation
  * Review configurations and security controls
  * Document lessons learned and areas for future improvement
