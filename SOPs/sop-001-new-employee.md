# SOP-001 - New Employee Onboarding

## Purpose

This SOP defines the standard process for onboarding a new employee at Acme Solutions Ltd. The process ensures that new employees receive the appropriate accounts, access, equipment, and resources required for their role.

## Scope

This procedure applies to all new employees joining Acme Solutions Ltd.

## Prerequisites

- HR has submitted an approved onboarding request.
- Employee information has been provided.
- Department and job role have been confirmed.
- Manager has approved required access.

## Procedure

1. Receive the onboarding request from HR.
2. Verify the employee's name, department, job title, and manager.
3. Create the employee's Active Directory account.
4. Place the account in the appropriate Organizational Unit (OU).
5. Add the user to the appropriate security groups.
6. Configure the employee's workstation.
7. Configure required file and shared-resource access.
8. Apply applicable security policies.
9. Verify authentication and required access.
10. Provide the employee with their account and workstation information.
11. Document completion of the onboarding request.

## Verification

- User can authenticate successfully.
- User is assigned to the correct OU.
- Required security groups are assigned.
- Required resources are accessible.
- Security policies are applied.

## Documentation

Record the completed onboarding activity in the appropriate IT ticket.
